# FDE 多模态预处理 Skill

版本：`fde-preprocess/1.0`

一句话：把多模态原始数据加工为可比较、可追溯的标准记录，按固定契约交接给主清洗流程。

## 范围

只做预处理：三层存储（原始层只读保真、证据层存定位与中间产物、结果层只存标准记录）、分模态标准化、跨模态对齐（时间、空间、语义）、预处理质量门。

不做：冲突裁决并给出最终事实、去重结论或删除数据、异常剔除判定、结构化抽取的事实认定、主清洗的验收回归，以及调度、入库、版本发布、报表生成。

## 用法

全文规范见 `SKILL.md`。触发句：当多模态原始数据需要统一格式、建立证据指针并完成时间、空间、语义对齐，供后续清洗使用时，使用本 skill。

执行铁律：每次读取数据后先交确认卡；指针完好率不到 100% 不得进入精确处理，断指针标 `broken`、阻断进结果层、不许静默修补；灰区只输出候选、证据和建议，不擅自绑定、不擅自删除。

## 阈值口径

文中凡未给定的阈值均标为待标定；给定的数值均注明为示例起点值、仅用于冷启动，不可改写为通用标准。项目使用前须用自家标注样本标定：先用 100 条找流程问题，修复后扩展到 1000 条验收。
